# Мылушко

Самостоятельный лендинг маленькой мастерской мыла ручной работы.

Сайт: https://cj-isus.github.io/mylushko/

## Содержимое

- `index.html` — тексты, цены, ссылки на VK и метаданные для соцсетей.
- `styles.css` — оформление и мобильная версия.
- `script.js` — увеличение фотографий с клавиатурным управлением.
- `assets/` — пять настоящих фотографий работ в WebP, локальные шрифты и лицензии.

Набор стоит 200 ₽. При покупке 5 мыл шестое в подарок.
Наличие, цвета, состав набора и передачу заказа обсуждают в VK:
https://vk.me/club242687448

Сайт не требует сборки, установки библиотек или внешних шрифтов.
Пути к ресурсам относительные. Метаданные `og:url` и `og:image` используют
собственный адрес сайта.

## Публикация

Отдельный публичный репозиторий: https://github.com/cj-isus/mylushko

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.
Изменения сайта отправляют только в этот репозиторий.

## Проверки

7 ноября 2026 года самостоятельная версия проверена в Chromium 153:
12 ширин от 320 до 1920 px, отсутствие горизонтального переполнения,
загрузка всех фотографий и четырёх локальных шрифтов, три фотографии галереи,
Enter, Esc, кнопка закрытия, фон, возврат фокуса и reduced motion.
Ссылка заказа доступна без JavaScript.

Адреса ссылок VK и открытие заказа в отдельной вкладке проверены.
Доступность внешних страниц VK из среды проверки не подтверждена:
HTTP-запросы к трём адресам завершились таймаутом.
